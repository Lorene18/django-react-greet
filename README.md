# Django + React Greet App

A small full-stack app.

- *Backend:* Django endpoint /api/greet/?name=Alice returns {"message": "Hello, Alice"}. With no name it returns "Hello, World".
- *Frontend:* React (Vite) component with an input and a Greet button that calls the endpoint and shows the message.

## Run it
Backend: py manage.py runserver
Frontend: cd frontend, npm install, npm run dev
